## Abrir o projeto

1. Clonar o repositorio.
2. No Android Studio, abrir a pasta que contem `settings.gradle.kts`.
3. Instalar os componentes do SDK e do JDK exigidos pela configuracao Gradle
   existente e sincronizar o projeto.
4. Executar o modulo `app` num emulador ou dispositivo Android.

O Gradle Wrapper esta incluido. Os ficheiros `.gradle.kts` configuram a
compilacao; o codigo da aplicacao e Java.
